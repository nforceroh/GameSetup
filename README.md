# GameSetup

Setup notes and scripts for my games, plus shared Linux gaming tools:

- [`DCS/`](DCS) — Digital Combat Simulator installed and launched through UMU;
  see [`DCS/README.md`](DCS/README.md) for the setup notes.
- [`StarCitizen/`](StarCitizen) — Star Citizen setup (notes pending).
- [`WoT/`](WoT) — World of Tanks, launched through [UMU](https://github.com/Open-Wine-Components/umu-launcher)
  with a Proton/GE-Proton compatibility tool. See [`WoT/README.md`](WoT/README.md)
  for the launcher itself.

## Shared tools

- [`umu-launcher/`](umu-launcher) — Fedora instructions for installing UMU and
  its `umu-run` command.
- [`Proton-GE/`](Proton-GE) — instructions and updater for GE-Proton, plus
  NTSync setup.

For WoT's `PROTONPATH`, runner selection, and DXVK details, see the
[WoT runner notes](WoT/README.md#updating-the-proton-runner-and-dxvk).
